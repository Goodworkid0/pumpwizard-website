# Engine instance comparison

Select **Compare** on two to four Engine cards, then open the comparison above the
catalog. Selection stays intact when searching, filtering or changing pages. The
URL's `compare` parameter stores the selected instance IDs in column order;
**Copy comparison link** shares that selection, not frozen results. Reloading a
shared link loads current public telemetry. Unavailable IDs remain removable and
are never replaced with an unrelated instance.

The table shows each instance's own all-time results and key settings. Dates and
initial funding are explicit. Matching dates/funding do not establish a controlled
test; there is no normalized shared period, winner badge or significance claim.
Unknown fields remain unknown, and no closed trades is distinct from a 0% win rate.
Fees remain included in reported P&L and are not deducted again.

Expandable configuration differences compare recorded configuration values and
the known version-specific policy fields, preserving missing versus false/zero.
Object key order is ignored, but ordered arrays such as target ladders are retained.
The data is descriptive; configurations alone may omit full signal implementations.
Use each instance's analysis and dated research export for further investigation.

Comparison reads the existing public report only. It does not start, stop, fund,
or modify strategies and does not fetch additional market data.
